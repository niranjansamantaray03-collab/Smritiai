# SmritiAI Android

SmritiAI is a dementia-care companion application.

## Current source

The current HTML application is preserved in:

../source_web/

The Android web asset copy is:

www/index.html

## Android package

Application ID:

com.smritiai.app

Version:

1.0.0

## Important

The Android project must ultimately use a secure backend for:

- authentication
- patient/caregiver connections
- tasks
- reminders
- cognitive game records
- RUDAS assessments
- memory stories
- mood
- synchronization

Do not store production patient data only in localStorage.

## Build

The final Android build can be performed using a cloud Android build environment if the local machine does not have Java/Android SDK installed.

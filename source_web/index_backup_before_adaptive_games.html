🛡️ Responsible AI

Purpose: SmritiAI is an academic prototype for cognitive support, memory assistance, routine support and cognitive stimulation.

What SmritiAI does

  • Provides memory assistance and reminders
  • Provides cognitive stimulation activities
  • Tracks user activity and task performance
  • Provides caregiver-oriented summaries
  • Supports routine recall

What SmritiAI does NOT do

  • Does not diagnose dementia
  • Does not assign dementia stages
  • Does not prescribe treatment
  • Does not replace clinical rehabilitation
  • Does not claim CDSCO clearance

Educational dementia-stage context

Early / Mild

Increasing forgetfulness and difficulty with complex tasks while retaining relatively greater independence.

Moderate / Middle

Greater difficulties with memory, communication and orientation, with increased need for assistance.

Severe / Late

Major dependence and substantial impairment affecting communication and daily activities.

These descriptions are educational only. SmritiAI does not determine which stage a person is in. Clinical validation, professional oversight and applicable regulatory assessment are required before clinical deployment.
